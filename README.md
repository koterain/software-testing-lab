# Практична робота: Створення автоматизованого тесту за допомогою штучного інтелекту та публікація коду на GitHub

* **Тестований вебсайт:** [YouTube Music](https://music.youtube.com/)
* **Інструмент ШІ:** Gemini

---

## Короткий опис автоматизованих перевірок

1. **Перевірка наявності елемента «Home» у меню.** Тест відкриває головну сторінку YouTube Music і перевіряє, чи відображається в інтерфейсі навігаційне посилання на головний екран.
2. **Перевірка правильного домену сторінки.** Скрипт валідує поточну адресу сайту та переконується, що завантажений URL повністю відповідає очікуваному домену платформи.
3. **Перевірка кнопки «Sign in» та переходу на сторінку авторизації.** Тест контролює видимість кнопки входу, виконує клік по ній та верифікує коректне перенаправлення користувача на сторінку логіну Google.

---

## Інструкція із запуску тестування

1. **Встановлення Node.js.** Для початку роботи необхідно встановити платформу Node.js на ваш комп'ютер.
2. **Клонування репозиторію.** Після встановлення середовища потрібно клонувати цей репозиторій на власний ПК.
3. **Встановлення залежностей.** Для завантаження всіх необхідних пакетів виконайте в терміналі команду:
   ```bash
   npm install
   ```
4. **Запуск тестів.** Для запуску написаних автоматизованих тестів виконайте команду:
   ```bash
   npm run test
   ```
